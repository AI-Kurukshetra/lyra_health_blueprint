# PRD

## Product
Enterprise mental wellness platform for employers, providers, and employees.

## MVP Outcomes
- Employee can complete intake and book first appointment in one journey.
- Provider can manage availability, appointments, notes, and messaging.
- Employer can view anonymized utilization and access metrics.
- Crisis flags are escalated and auditable.

## Personas
- Employee
- Provider
- Employer Admin
- System Admin

## In Scope (MVP)
- Auth + RBAC + multi-tenant isolation
- Self-assessment
- Deterministic therapist matching
- Appointment scheduling
- Session tracking
- Secure messaging
- Mood/progress tracking
- Resource library
- Employer analytics (anonymized)
- Compliance/audit logs

## Out of Scope (MVP)
- Insurance claims processing
- Advanced ML prediction models
- Native mobile apps
